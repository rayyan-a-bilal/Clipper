# Transcription Pipeline Specification (M2a - Transcript Foundations)

## ASR Configuration

All ASR adapters run on GPU0 only, never on the P100s.

Default configuration:
- model: large-v3-turbo
- compute_type: float16  
- word_timestamps: True
- vad_filter: True
- condition_on_previous_text: False

## Artifact Output

Artifacts are written to stage output directory with schema_version=1:

### words.json
The raw word-level timestamps from ASR, formatted as:
```json
{
  "schema_version": 1,
  "words": [
    {
      "start": float,
      "end": float, 
      "text": str,
      "prob": float
    }
  ]
}
```

### sentences.json
A sentence-level representation of the transcript with:
```json
{
  "schema_version": 1,
  "sentences": [
    {
      "start": float,
      "end": float,
      "text": str,
      "word_idx": [int, int]
    }
  ]
}
```

## Stage Names

- transcribe: runs ASR on audio input to generate words.json
- sentences: builds sentences from words.json to generate sentences.json

## Sentence Building Rules

1. **Punctuation-based sentence splitting**:
   - Split after word ending in . ? !

2. **Gap-based sentence splitting**:  
   - Split when inter-word gap > 0.6s

3. **Duration-based sentence splitting**:
   - Max sentence duration 12.0s
   - Long sentences split recursively at largest internal gap until <= 12.0s or only one word remains

4. **Word indices**: 
   - Sentence.word_idx is inclusive global word indices 
   - First word = index 0, second word = index 1, etc.

5. **Data structure**:
   - Input words are chronological; do not reorder them
   - Ignore words whose stripped text is empty

## Stage Behavior

### transcribe
- Accepts input audio file path
- Produces words.json artifact

### sentences  
- Reads words.json artifact from transcribe stage
- Produces sentences.json artifact

## Tests Requirements

All tests must:
- Never require GPU, CUDA, model downloads, or live LLM
- Use only fixtures and CPU-only processing 
- Be deterministic and reproducible
- Validate schema version 1 of artifacts
