# M7 — GPU Render Pipeline (M7a: caption engine + render contracts; M7b: mezzanine render + audio extraction)

M7 turns DRAFT ClipPlans (`status=pending_qc`, M5/M6) into final vertical
clips. **M7a is contracts + pure caption engine ONLY — NO rendering
adapters, NO render stage, NO render script** (those are M7b+).

Hardware authority: `.agents/skills/clipper-project/SKILL.md` (Hardware +
M6/M7 GPU rules) and `docs/spec/pipeline.md`. There is no `docs/spec/gpu.md`;
one is deliberately NOT created (M6 precedent).

## Fixed M7 decisions (authoritative for M7b+)

1. **Production render uses NVDEC decode + NVENC encode on GPU0 only**
   (RTX 2080 Super, `cuda:0` / `cfg.render.hwaccel = "cuda"`). The P100s
   (GPU1/GPU2) never do video decode/encode (no NVENC/NVDEC).
2. **No libx264 production path.** CPU rendering exists ONLY behind an
   explicit `cfg.render.cpu_render = true` (CLI `--cpu-render` when wired),
   logged loudly. It is a debug path, not a fallback — HW failure fails
   loudly instead of silently degrading (M6a precedent).
3. GPU crop/scale/composite where supported; **libass caption burn is CPU**
   (ffmpeg `ass=` filter); audio `loudnorm` is CPU.
4. **Per-clip outputs** in `data/jobs/<job_id>/clips/<clip_id>/`:
   `mezzanine.mp4`, `audio.m4a`, `captions.ass`, `final.mp4`,
   `thumbnail.jpg`, `render.json`.
5. **Final output**: 1080x1920, native fps (carried from the probe/source,
   not re-timed), H.264 via `h264_nvenc`, AAC audio.
6. **Audio loudness**: `loudnorm I=-16:TP=-1.5:LRA=11`.
7. **Captions are clip-relative** (t=0 at clip start), burned via ASS (see
   M7a below).
8. **`center_crop` static path must render correctly even with
   `faces == 0`** (M6 produces a static exact-9:16 `main` track in that
   case; the renderer must not require face tracks to be non-empty).

### `src/clipper/captions.py` — PURE (imports `clipper.config` +
`clipper.models` only; no I/O, no ffmpeg, no numpy)

`words_to_ass(words: list[Word], plan: ClipPlan, cfg: Config) -> str`:

- select words OVERLAPPING `[plan.start, plan.end]`
  (`w.end > plan.start and w.start < plan.end`); all others excluded
- timestamps CONVERTED TO CLIP-RELATIVE (subtract `plan.start`); a word
  that overlaps from before the cut is clamped to relative `t >= 0`
  (judgment note)
- grouping, greedy in word order (deterministic): a word joins the current
  LINE iff the current group has < `max_words_per_group (4)` words AND it
  fits char-wise (`line_chars + 1 + len(word) <= max_chars_per_line (20)`);
  else it opens a NEW LINE in the same group iff the group has < 4 words AND
  it has < `max_lines (2)` lines; else the group is FLUSHED and a new group
  starts with the word as its first line. Invariants per group: <= 4 words,
  <= 2 lines, <= 20 chars/line — **no word is ever dropped**. A word longer
  than one line takes a line to itself (it is never split; judgment note)
- **min display 0.6s** per group (`MIN_DISPLAY_S`): group end = next
  group's first-word start (or the last word's end for the final group),
  raised to `start + 0.6` when shorter
- **karaoke** per word: `{\kf<cs>}{\c&H00FFFF&}<word>{\r}{\c&HFFFFFF&}<word>`
  — unsung highlight yellow (`&H00FFFF&`), sung white (`&HFFFFFF&`);
  `<cs>` = word duration in centiseconds, `max(1, round)`
- **Caption style** (from cfg where it exists): Fontname
  `cfg.captions.font`, Fontsize `cfg.captions.font_size` (88),
  Bold 1, BorderStyle 1, Outline 4, Shadow 0, Alignment 2 (bottom center),
  MarginL = MarginR = `cfg.captions.safe_zone_right` (150),
  MarginV = `cfg.captions.margin_v` (450)
- **Hook overlay style** (separate, top): same font, Fontsize
  `HOOK_FONT_SIZE = 72` (fixed — judgment note), Bold 1, Outline 4,
  Shadow 0, Alignment 8 (top center), MarginL = MarginR = safe zone right,
  MarginV = `cfg.captions.safe_zone_top` (220 — respects the top safe
  zone). Event text = `plan.hook_overlay` (verbatim, newlines to `\N`),
  `start = 0`, `end = min(cfg.clips.hook_overlay_duration (2.5s),
  plan duration)`. Emitted only when `plan.hook_overlay` is non-empty
  (judgment note: keeps the empty-words case an event-free document)
- `PlayResX/PlayResY` = `cfg.render.output_width/height` (1080x1920)
- **deterministic**: same inputs → byte-identical ASS; fixed section
  order `[Script Info]` → `[V4+ Styles]` → `[Events]`; events in word
  order; no timestamps-of-generation, no randomness. Empty `words` →
  valid ASS with styles and ZERO caption events.

## Judgment notes (simplest boring option, per no-drift rule)

- Pre-cut overlapping word clamps to relative `t = 0` (its `\kf` span
  uses the clamped interval) — never a negative ASS timestamp.
- A single word longer than `max_chars_per_line` keeps the WHOLE word on
  its own line rather than splitting it (simpler, readable, spec-faithful
  "words are the unit").
- Hook overlay is a separate STYLE + event (not per-word karaoke), shown
  a fixed 2.5s (cfg `clips.hook_overlay_duration`), capped by clip
  duration; empty `hook_overlay` → no hook event.
- Group end time = next group's FIRST WORD START (continuous karaoke);
  the 0.6s minimum may overlap the next group — standard ASS behavior.
- `MezzanineInfo`/`ClipAudioInfo` carry `schema_version=1` (mirrors the
  persisted `ProxyInfo`/`AudioInfo` artifacts; `VisionSegmentInfo` — the
  only schema-less info — has no on-disk artifact).

## M7b decisions (fixed — render adapter + preflight)

### `src/clipper/adapters/render.py` (re-exported from `clipper.adapters`)

- `RenderAdapter` protocol (`runtime_checkable`):
  - `render_mezzanine(source, plan, layout, dst, cfg, native_fps=None) -> MezzanineInfo`
  - `extract_audio(source, start_s, end_s, dst) -> ClipAudioInfo`
- `FFmpegRenderAdapter`: subprocess ffmpeg, `MediaError` (stderr tail) on
  every failure — **NO silent encode fallback** (decision 2).
  - **Mezzanine, `center_crop` static path ONLY (M7b)** — any other
    `Layout` (or unknown string) raises a clean `MediaError`. This
    covers decision 8: the static crop vf needs no face tracks
    (`faces == 0` renders correctly). Tracking/composite rendering
    (face_track/split_screen/facecam) is a LATER M7 milestone.
  - `center_crop` vf (exact 9:16 window, even width, centered — same
    geometry rule as the M6d `exact-9kx16k` window):
    - **GPU scale (default when `scale_cuda` is present):**
      `vf = crop=w=trunc(ih*9/16/2)*2:h=ih:x=(iw-ow)/2:y=0,
hwupload_cuda,scale_cuda={W}:{H}:format=nv12` → full command
      `ffmpeg -hide_banner -loglevel error -y -hwaccel cuda
      -ss {plan.start} -to {plan.end} -i {source} -vf {vf} -an
      -c:v h264_nvenc -preset {cfg.render.nvenc_preset} -rc vbr
      -cq {cfg.render.mezz_cq} -r {native_fps} {dst}`
      (W/H = `cfg.render.output_width/height`, 1080x1920 defaults)
    - **CPU-scale fallback (only when `scale_cuda` is ABSENT):**
      `vf = crop=...,scale={W}:{H}:flags=lanczos`, NO `-hwaccel`,
      encode STAYS `h264_nvenc`, and a **LOUD warning**
      (`CPU_SCALE_FALLBACK_WARNING`, logger `WARNING`) is logged. This
      is the documented debug allowance — NOT a silent path.
    - **`cpu_render=True` (EXPLICIT debug path, decision 2):** NO
      `-hwaccel`, CPU scale (`flags=lanczos`), encode `libx264
      -crf {cfg.render.crf}` — the ONLY sanctioned libx264 use, and it
      can never be selected implicitly (factory + render both log
      `CPU_RENDER_WARNING` loudly).
  - `scale_cuda` auto-detected via `ffmpeg -filters` (cached per
    instance);
    detection failure → CPU-scale fallback + loud warning, never a
    crash.
  - `extract_audio` command (verbatim): `ffmpeg -hide_banner
    -loglevel error -y -ss {start_s} -to {end_s} -i {source} -vn -ac 2
    -ar 48000 -c:a aac -b:a 192k {dst}` → loudnorm (`I=-16:TP=-1.5:
    LRA=11`) is a LATER-M7 final-compose step (decision 6), NOT part
    of M7b extraction.
  - Both commands are **probed after success** to fill the M7a
    contracts: mezzanine via `probe()` → `MezzanineInfo{width,
    height, fps, duration_s}`; audio via ffprobe stream
    (`sample_rate`, `channels`) + format `duration` (fallback
    `end-start`) → `ClipAudioInfo`.
- `FixtureRenderAdapter`: writes placeholder files; canned valid
  `MezzanineInfo` (1080x1920 from `cfg.render`, duration =
  `plan.end - plan.start`, fps 30.0 or caller-provided) / `ClipAudioInfo
  (48000 Hz, 2 ch, duration = `end - start`); same layout guard.
- `get_render_adapter(cfg, cpu_render=None)` factory (singleton, like
  `get_adapter`): `cpu_render=True` (arg or `cfg.render.cpu_render`)
  → `FFmpegRenderAdapter(cpu_render=True)` + **loud warning**; else
  `cfg.devices.vision in ("fixture","mock")` → `FixtureRenderAdapter`;
  else production `FFmpegRenderAdapter`. `reset_render_adapter()` is a
  test helper.

### `scripts/render_preflight.py` (MANUAL)

- REQUIRED (exit 1 on any failure): `ffmpeg -hwaccels` contains
  `cuda`; `ffmpeg -encoders` contains `h264_nvenc`; `ffmpeg -filters`
  contains `ass`. ffmpeg missing → immediate exit 1.
- WARN-ONLY: `scale_cuda` present = GPU-scale path; **absent = CPU-scale
  fallback ALLOWED** (adapter will log loudly).
- Prints per-check PASS/FAIL/WARN + RESULT line; exit 0/1.

### Judgment notes (per no-drift rule)

- `render_mezzanine` gained ONE keyword-only optional `native_fps`
  parameter (judgment note, like the M6d/M6e pattern): when `None` the
  FFmpeg impl probes the SOURCE for the native fps (the card signature
  has no probe step in it); a probed/passed `native_fps <= 0` FAILS
  LOUDLY (no re-time default) rather than guessing 30.0.
- `cpu_render` debug path encodes with `libx264 -crf {cfg.render.crf}`
  (the one sanctioned CPU encode; never reachable implicitly). The
  `scale_cuda`-absent fallback keeps the NVENC encode (the
  `pipeline.md` libx264-final line is superseded by decision 2 for
  M7b, which covers mezzanine only).
- Audio loudnorm is deliberately NOT applied in M7b extraction
  (`extract_audio` returns the raw-window AAC); it belongs to the
  later-M7 final compose (decision 6 ordering).
- `MezzanineInfo` duration comes from the ffprobe FORMAT duration of
  the rendered file (not `plan.end - plan.start`), matching the
  "probe outputs to fill contracts" card requirement.
