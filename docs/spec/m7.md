# M7 — GPU Render Pipeline (M7a: caption engine + render contracts; M7b: mezzanine render + audio extraction)

M7 turns DRAFT ClipPlans (`status=pending_qc`, M5/M6) into final vertical
clips. **M7a is contracts + pure caption engine ONLY — NO rendering
adapters, NO render stage, NO render script** (those are M7b+).

Hardware authority: `.agents/skills/clipper-project/SKILL.md` (Hardware +
M6/M7 GPU rules) and `docs/spec/pipeline.md`. There is no `docs/spec/gpu.md`;
one is deliberately NOT created (M6 precedent).

## Fixed M7 decisions (authoritative for M7b+)

1. **Production render uses NVDEC decode + NVENC encode on GPU0 only**
   (RTX 2080 Super, `cuda:0` / `cfg.render.hwaccel = "cuda"`). The P100s
   (GPU1/GPU2) never do video decode/encode (no NVENC/NVDEC).
2. **No libx264 production path.** CPU rendering exists ONLY behind an
   explicit `cfg.render.cpu_render = true` (CLI `--cpu-render` when wired),
   logged loudly. It is a debug path, not a fallback — HW failure fails
   loudly instead of silently degrading (M6a precedent).
3. GPU crop/scale/composite where supported; **libass caption burn is CPU**
   (ffmpeg `ass=` filter); audio `loudnorm` is CPU.
4. **Per-clip outputs** in `data/jobs/<job_id>/clips/<clip_id>/`:
   `mezzanine.mp4`, `audio.m4a`, `captions.ass`, `final.mp4`,
   `thumbnail.jpg`, `render.json`.
5. **Final output**: 1080x1920, native fps (carried from the probe/source,
   not re-timed), H.264 via `h264_nvenc`, AAC audio.
6. **Audio loudness**: `loudnorm I=-16:TP=-1.5:LRA=11`.
7. **Captions are clip-relative** (t=0 at clip start), burned via ASS (see
   M7a below).
8. **`center_crop` static path must render correctly even with
   `faces == 0`** (M6 produces a static exact-9:16 `main` track in that
   case; the renderer must not require face tracks to be non-empty).

### `src/clipper/captions.py` — PURE (imports `clipper.config` +
`clipper.models` only; no I/O, no ffmpeg, no numpy)

`words_to_ass(words: list[Word], plan: ClipPlan, cfg: Config) -> str`:

- select words OVERLAPPING `[plan.start, plan.end]`
  (`w.end > plan.start and w.start < plan.end`); all others excluded
- timestamps CONVERTED TO CLIP-RELATIVE (subtract `plan.start`); a word
  that overlaps from before the cut is clamped to relative `t >= 0`
  (judgment note)
- grouping, greedy in word order (deterministic): a word joins the current
  LINE iff the current group has < `max_words_per_group (4)` words AND it
  fits char-wise (`line_chars + 1 + len(word) <= max_chars_per_line (20)`);
  else it opens a NEW LINE in the same group iff the group has < 4 words AND
  it has < `max_lines (2)` lines; else the group is FLUSHED and a new group
  starts with the word as its first line. Invariants per group: <= 4 words,
  <= 2 lines, <= 20 chars/line — **no word is ever dropped**. A word longer
  than one line takes a line to itself (it is never split; judgment note)
- **min display 0.6s** per group (`MIN_DISPLAY_S`): group end = next
  group's first-word start (or the last word's end for the final group),
  raised to `start + 0.6` when shorter
- **karaoke** per word: `{\kf<cs>}{\c&H00FFFF&}<word>{\r}{\c&HFFFFFF&}<word>`
  — unsung highlight yellow (`&H00FFFF&`), sung white (`&HFFFFFF&`);
  `<cs>` = word duration in centiseconds, `max(1, round)`
- **Caption style** (from cfg where it exists): Fontname
  `cfg.captions.font`, Fontsize `cfg.captions.font_size` (88),
  Bold 1, BorderStyle 1, Outline 4, Shadow 0, Alignment 2 (bottom center),
  MarginL = MarginR = `cfg.captions.safe_zone_right` (150),
  MarginV = `cfg.captions.margin_v` (450)
- **Hook overlay style** (separate, top): same font, Fontsize
  `HOOK_FONT_SIZE = 72` (fixed — judgment note), Bold 1, Outline 4,
  Shadow 0, Alignment 8 (top center), MarginL = MarginR = safe zone right,
  MarginV = `cfg.captions.safe_zone_top` (220 — respects the top safe
  zone). Event text = `plan.hook_overlay` (verbatim, newlines to `\N`),
  `start = 0`, `end = min(cfg.clips.hook_overlay_duration (2.5s),
  plan duration)`. Emitted only when `plan.hook_overlay` is non-empty
  (judgment note: keeps the empty-words case an event-free document)
- `PlayResX/PlayResY` = `cfg.render.output_width/height` (1080x1920)
- **deterministic**: same inputs → byte-identical ASS; fixed section
  order `[Script Info]` → `[V4+ Styles]` → `[Events]`; events in word
  order; no timestamps-of-generation, no randomness. Empty `words` →
  valid ASS with styles and ZERO caption events.

## Judgment notes (simplest boring option, per no-drift rule)

- Pre-cut overlapping word clamps to relative `t = 0` (its `\kf` span
  uses the clamped interval) — never a negative ASS timestamp.
- A single word longer than `max_chars_per_line` keeps the WHOLE word on
  its own line rather than splitting it (simpler, readable, spec-faithful
  "words are the unit").
- Hook overlay is a separate STYLE + event (not per-word karaoke), shown
  a fixed 2.5s (cfg `clips.hook_overlay_duration`), capped by clip
  duration; empty `hook_overlay` → no hook event.
- Group end time = next group's FIRST WORD START (continuous karaoke);
  the 0.6s minimum may overlap the next group — standard ASS behavior.
- `MezzanineInfo`/`ClipAudioInfo` carry `schema_version=1` (mirrors the
  persisted `ProxyInfo`/`AudioInfo` artifacts; `VisionSegmentInfo` — the
  only schema-less info — has no on-disk artifact).

## M7b decisions (fixed — render adapter + preflight)

### `src/clipper/adapters/render.py` (re-exported from `clipper.adapters`)

- `RenderAdapter` protocol (`runtime_checkable`):
  - `render_mezzanine(source, plan, layout, dst, cfg, native_fps=None) -> MezzanineInfo`
  - `extract_audio(source, start_s, end_s, dst) -> ClipAudioInfo`
- `FFmpegRenderAdapter`: subprocess ffmpeg, `MediaError` (stderr tail) on
  every failure — **NO silent encode fallback** (decision 2).
  - **Mezzanine, `center_crop` static path ONLY (M7b)** — any other
    `Layout` (or unknown string) raises a clean `MediaError`. This
    covers decision 8: the static crop vf needs no face tracks
    (`faces == 0` renders correctly). Tracking/composite rendering
    (face_track/split_screen/facecam) is a LATER M7 milestone.
  - `center_crop` vf (exact 9:16 window, even width, centered — same
    geometry rule as the M6d `exact-9kx16k` window):
    - **GPU scale (default when `scale_cuda` is present):**
      `vf = crop=w=trunc(ih*9/16/2)*2:h=ih:x=(iw-ow)/2:y=0,
hwupload_cuda,scale_cuda={W}:{H}:format=nv12` → full command
      `ffmpeg -hide_banner -loglevel error -y -hwaccel cuda
      -ss {plan.start} -to {plan.end} -i {source} -vf {vf} -an
      -c:v h264_nvenc -preset {cfg.render.nvenc_preset} -rc vbr
      -cq {cfg.render.mezz_cq} -r {native_fps} {dst}`
      (W/H = `cfg.render.output_width/height`, 1080x1920 defaults)
    - **CPU-scale fallback (only when `scale_cuda` is ABSENT):**
      `vf = crop=...,scale={W}:{H}:flags=lanczos`, NO `-hwaccel`,
      encode STAYS `h264_nvenc`, and a **LOUD warning**
      (`CPU_SCALE_FALLBACK_WARNING`, logger `WARNING`) is logged. This
      is the documented debug allowance — NOT a silent path.
    - **`cpu_render=True` (EXPLICIT debug path, decision 2):** NO
      `-hwaccel`, CPU scale (`flags=lanczos`), encode `libx264
      -crf {cfg.render.crf}` — the ONLY sanctioned libx264 use, and it
      can never be selected implicitly (factory + render both log
      `CPU_RENDER_WARNING` loudly).
  - `scale_cuda` auto-detected via `ffmpeg -filters` (cached per
    instance);
    detection failure → CPU-scale fallback + loud warning, never a
    crash.
  - `extract_audio` command (verbatim): `ffmpeg -hide_banner
    -loglevel error -y -ss {start_s} -to {end_s} -i {source} -vn -ac 2
    -ar 48000 -c:a aac -b:a 192k {dst}` → loudnorm (`I=-16:TP=-1.5:
    LRA=11`) is a LATER-M7 final-compose step (decision 6), NOT part
    of M7b extraction.
  - Both commands are **probed after success** to fill the M7a
    contracts: mezzanine via `probe()` → `MezzanineInfo{width,
    height, fps, duration_s}`; audio via ffprobe stream
    (`sample_rate`, `channels`) + format `duration` (fallback
    `end-start`) → `ClipAudioInfo`.
- `FixtureRenderAdapter`: writes placeholder files; canned valid
  `MezzanineInfo` (1080x1920 from `cfg.render`, duration =
  `plan.end - plan.start`, fps 30.0 or caller-provided) / `ClipAudioInfo
  (48000 Hz, 2 ch, duration = `end - start`); same layout guard.
- `get_render_adapter(cfg, cpu_render=None)` factory (singleton, like
  `get_adapter`): `cpu_render=True` (arg or `cfg.render.cpu_render`)
  → `FFmpegRenderAdapter(cpu_render=True)` + **loud warning**; else
  `cfg.devices.vision in ("fixture","mock")` → `FixtureRenderAdapter`;
  else production `FFmpegRenderAdapter`. `reset_render_adapter()` is a
  test helper.

- `render_mezzanine` gained ONE keyword-only optional `native_fps`

- `cpu_render` debug path encodes with `libx264 -crf {cfg.render.crf}`
  (the one sanctioned CPU encode; never reachable implicitly). The

- `MezzanineInfo` duration comes from the ffprobe FORMAT duration of
  the rendered file (not `plan.end - plan.start`), matching the
  "probe outputs to fill contracts" card requirement.

### `FFmpegRenderAdapter.compose_final(...)` — final compose

- Command (verbatim, docs/spec/m7.md M7c):

      ffmpeg -hide_banner -loglevel error -y -i {mezz} -i {audio}
             -vf "ass={ass_path}:fontsdir={assets/fonts}"
             -af "loudnorm=I=-16:TP=-1.5:LRA=11"
             -c:v h264_nvenc -preset {nvenc_preset} -rc vbr -cq {final_cq}
             -c:a aac -b:a 160k -movflags +faststart -shortest {dst}

- `fontsdir` = the repo's `assets/fonts` directory (resolved from the
  source tree — `clipper/adapters/render.py::_fonts_dir()`).
- `ass` filter is REQUIRED: `ass_filter_available()` probes
  `ffmpeg -filters` (cached per instance, token match). Missing →
  clean `MediaError` naming the missing `ass` filter (reinstall an
  ffmpeg built with libass). Missing font → clean `MediaError`
  naming `assets/fonts/Montserrat-ExtraBold.ttf` AND the install
  script `bash scripts/install_fonts.sh`. Both checks happen BEFORE
  any encode (no partial output).
- Encodes with `h264_nvenc` (decision 1); `loudnorm` is the CPU audio
  step (decisions 3/6); AAC 160k; `+faststart` for web playback;
  `-shortest` bounds the final by the shorter input.
- The result is **probed** (`FFmpegMediaAdapter.probe`) to fill
  `width`/`height`/`fps`/`duration_s`.
- Returns a **PARTIAL `RenderArtifact`**: `clip_id=""` and
  `thumbnail_path=""` are filled by the (later M7) render STAGE;
  `encoder="h264_nvenc"`, `hwaccel=cfg.render.hwaccel` (`"cuda"`);
  `render_seconds` covers this ffmpeg invocation only.
- Missing mezzanine/audio/captions input files → clean `MediaError`
  naming which input is missing.

### `FFmpegRenderAdapter.make_thumbnail(final, dst) -> str`

- Command (verbatim): `ffmpeg -ss 1.0 -i {final} -vframes 1 {dst}`
  (input-seek at t=1.0s, single still frame); returns `dst`.
  Missing `final` → clean `MediaError`.

### `src/clipper/stages/render.py`

`run_render(job_id, cfg, conn, render: RenderAdapter,
clip_id: str | None = None, cpu_render: bool = False) -> dict`

- stage name: `render`; ADAPTER INJECTED (protocol, never constructed in
  the stage — M6e pattern); `FixtureRenderAdapter` in tests.
- required inputs (each `schema_version == 1`; clean `StageError` names
  the missing artifact AND the milestone/script that produces it):
  - `clip_plans.json` (M5C-5, `scripts/select_job.py`)
  - `words.json` (M2b, `scripts/transcribe_job.py`)
  - `probe.json` (M1, `python -m clipper ingest`)
  - per clip: `clips/<clip_id>/layout.json` (M6e,
    `scripts/layout_job.py`; validated, `clip_id` must match)
- for each ClipPlan (or only `clip_id`):
  1. `render.render_mezzanine(source, plan, layout, clips/<cid>/mezzanine.mp4, cfg, native_fps=probe.fps)`
  2. `render.extract_audio(source, plan.start, plan.end, clips/<cid>/audio.m4a)`
  3. `captions.words_to_ass(words, plan, cfg)` → `clips/<cid>/captions.ass` (pure M7a engine, written verbatim)
  4. `render.compose_final(mez.path, audio.path, ass, clips/<cid>/final.mp4, cfg)`
  5. `render.make_thumbnail(final, clips/<cid>/thumbnail.jpg)`
  6. `render.json` = the PARTIAL `RenderArtifact` from `compose_final` with `clip_id` + `thumbnail_path` filled by the stage (canonical `model_dump_json(indent=2)` + newline)
- `ClipPlan.status` → `"rendered"` (all other fields intact);
  `clip_plans.json` rewritten in full (in order); `clips` rows upserted.
- skip rule: DB stage `done` AND, for EVERY scoped clip, `final.mp4`
  exists AND `render.json` validates (`RenderArtifact`,
  `schema_version == 1`, matching `clip_id`, valid `final_path` file).
  The skip summary reports each clip from its `render.json`.
- job `queued -> running -> queued` on success; failure marks stage +
  job `failed` and raises clean `StageError` (non-`StageError` — e.g.
  `MediaError` — is wrapped, original preserved in the chain; a later
  retry re-runs the stage).
- ZERO plans = VALID success (stage `done`, job `queued`, adapter never
  invoked; the re-run then skips).
- `cpu_render=True` logs the adapter module's `CPU_RENDER_WARNING`
  (WARNING level, stage logger `clipper.stages.render`) at stage entry —
  the explicit debug path (decision 2).
- `stages/__init__.py` re-exports `run_render`.

### `scripts/render_job.py`

`python scripts/render_job.py JOB_ID [--clip CLIP_ID] [--cpu-render]`

- default = GPU path (`get_render_adapter(cfg)`, NVDEC/NVENC);
  `--cpu-render` = EXPLICIT debug path: prints the LOUD
  `CPU_RENDER_WARNING` and forwards `cpu_render=True` to the factory.
- prints per clip: `clip_id`, final path, duration, width x height
  (+ fps), encoder, `render_seconds`; zero clips → "VALID success";
  skip → "skipped" note.
- exit 0 on success (incl. zero clips / skip), exit 1 clean error
  (`StageError` / `MediaError`).

### Judgment notes (per no-drift rule)

- The stage passes `native_fps=probe.fps` to `render_mezzanine`
  (`probe.json` is a REQUIRED input per this milestone; a non-positive
  fps fails LOUDLY in the FFmpeg adapter — no 30.0 guess, M7b rule).
  The `FixtureRenderAdapter` defaults to 30.0.
- `compose_final`'s PARTIAL `RenderArtifact` is completed by
  `model_copy(update={clip_id, thumbnail_path})` — all other fields
  (geometry/encoder/hwaccel/`render_seconds`) come from the adapter.
- `render_seconds` in `render.json` measures the compose invocation only
  (M7c judgment, unchanged); `elapsed_seconds` in the summary dict is
  the whole per-clip stage work (informational, not persisted).
- The `RenderAdapter` has no `close()` (stateless factory singleton) —
  unlike the M6e detector, the stage adds no `finally` cleanup.

### Decisions (geometry, per the M7f card — output width 1080)

- `split_screen`: the M6d/M6e `top` and `bottom` `RegionTrack`s —
  STATIC t=0 keys — cropped from the source, each scaled to **1080x960**
  (`SPLIT_REGION_HEIGHT = 960`), stacked with `vstack=inputs=2` →
  1080x1920.
- `facecam`: the `main` track cropped + scaled to a **1080x608** TOP
  band (`FACECAM_MAIN_HEIGHT = 608`); the `face` track aspect-FIT (even
  dims) into the **1080x1312** bottom band; when the face region's
  aspect DIFFERS from the band, a BLURRED FILL sits behind it — `scale`
  cover + `crop=1080:1312` + `boxblur=8:1.5` (`FACECAM_BLUR`) +
  `overlay=(W-w)/2:(H-h)/2`; both bands `vstack` → 1080x1920
  (608 + 1312 = 1920).

### Decisions (region sourcing, clean failure)

- Region tracks come from the M6e `layout.json`
  (`ClipLayoutArtifact.tracks`, roles `top/bottom/main/face`) and are
  plumbed stage → adapter via a new `render_mezzanine(..., tracks=...)`
  keyword (the stage passes `layout_art.tracks`; the `RenderAdapter`
  protocol gains the optional `tracks` keyword, ignored by
  center_crop/face_track).
- A MISSING `tracks` list, or an ABSENT required role, or a track with
  NO keys raises a clean `MediaError` naming the role AND the M6e
  producer (`stages/layout.py`, `scripts/layout_job.py`) — no silent
  default, no partial encode. Applies to both `FFmpegRenderAdapter` and
  `FixtureRenderAdapter` BEFORE any output is written.

### Decisions (encode/scale rules unchanged — M7b decision 2)

- MULTI-REGION paths use `-filter_complex` (labeled `[0:v]` chains —
  `[top]`/`[bottom]` or `[main]`/`[face]`/`[bg]`/`[bot]` — ending in
  `...vstack=inputs=2[vout]`) + `-map [vout]`; `-an`; input-seek
  `-ss/-to -i` first; encode `-c:v h264_nvenc -preset {nvenc_preset}
  -rc vbr -cq {mezz_cq}` + `-r {native_fps}` (M7d: probed source fps).
- Per-band scaling is `hwupload_cuda,scale_cuda=W:H:format=nv12`,
  `hwdownload_cuda,format=nv12` when the `scale_cuda` filter exists —
  BUT composite (`vstack` / `overlay` / `boxblur`) is ALWAYS CPU on
  filter_complex (decision 3, no GPU composite variant); `-hwaccel cuda`
  (NVDEC) is present ONLY on the GPU path.
- CPU-scale fallback (scale_cuda ABSENT): per-band
  `scale=W:H:flags=lanczos`, NO `-hwaccel`, encode STILL `h264_nvenc`,
  and the LOUD `CPU_SCALE_FALLBACK_WARNING` (decision 2 verbatim).
- `cpu_render=True` explicit debug path unchanged (CPU scale,
  `libx264 -crf`, double-loud). **NO `libx264` in ANY production
  command** (all four layouts).

### `scripts/bench_m7.py` (bench proof — REQUIRED by the M7f card)

`python scripts/bench_m7.py <job-id>`:

- runs the M7d render stage once, with a timing wrapper (per-call wall
  seconds recorded for `render_mezzanine` and `compose_final`; the
  stage does ONE of each per clip IN PLAN ORDER → positional slice,
  bench_m6 pattern: stage is NOT edited),

  `utilization.encoder` = NVENC activity) every 0.5s in a background
  thread while it runs,
- writes, per clip, `data/jobs/<job_id>/clips/<clip_id>/bench.json`
  with EXACTLY these fields (types): `clip_id: str`,
  `mezzanine_seconds: float`, `compose_seconds: float`,
  `total_seconds: float`, `decode_fps: float`, `encode_fps: float`,
  `output_fps: float`, `frames_processed: int`, `peak_gpu0_util: int`,
  `nvenc_session_seen: bool`, `encoder: str`, `hwaccel: str` — and
  prints a summary table; exit 0/1.
- `frames_processed` = final.mp4 frame count (`ffprobe
  -count_frames nb_read_frames`; `duration × avg_frame_rate` fallback);
  `decode_fps` = frames/mezzanine_seconds (NVDEC + crop/scale),
  `encode_fps` = frames/compose_seconds (NVENC pass) — a documented
  approximation (per-stage counters are not exposed by ffmpeg);
  `output_fps` from final-frame fps; `peak_gpu0_util` = max
  `utilization.gpu` sample; `nvenc_session_seen` =
  `utilization.encoder > 0` sampled (the NVENC session proof);
  `encoder`/`hwaccel` read back from the stage `render.json` (NVDEC /
  NVENC proof).
